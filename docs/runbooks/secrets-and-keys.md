# Runbook: secrets and keys

Rules SE-010, SE-030..SE-033; ADR-0011.

## What exists
`.secrets/` (gitignored, `0700`), generated by `make secrets`: Postgres role passwords, NATS users, Valkey ACL, `gateway_auth_key` (TOTP sealing + code HMAC), `broker_kek` (broker-credential KEK ring), Ed25519 service keys, Grafana admin password, backup age identity/recipient, optional Pushover/Cloudflare tokens (placeholders `unset`).

## Escrow (do this before storing live broker credentials)
Copy to a password manager or hardware-backed vault, off the Mac: `backup_age_identity`, `broker_kek`, `gateway_auth_key`. Optionally `make secrets-encrypt` and keep `infra/secrets/local.sops.yaml` with your backups; restoring it needs your age identity (`make secrets-decrypt AGE_KEY_FILE=...`).

Losing `broker_kek` makes stored broker credentials unrecoverable (re-enter them). Losing `gateway_auth_key` invalidates TOTP enrollment and recovery codes (log in with a passkey and re-enroll).

## Rotate
| Secret | How |
|---|---|
| Broker KEK | Prepend `k2:<base64 32 bytes>` to `.secrets/broker_kek` (keep `k1`), restart broker-gateway, run `docker compose -f infra/compose/docker-compose.yml exec broker-gateway /app/service rewrap-keys`, verify, then remove `k1` and restart |
| Broker API key | Rotate at the broker, then store the new key from Broker connections (step-up) |
| DB / NATS / Valkey passwords | Delete the file, `make secrets`, `make migrate` (resets role passwords), restart services |
| Service signing keys | Delete `svc_<name>_ed25519*`, `make secrets`, restart the caller and receivers |
| Gateway key | Delete `gateway_auth_key`, `make secrets`, restart api-gateway; re-enroll TOTP and regenerate recovery codes |

Never paste secret values into issues, logs, chat, or LLM prompts.

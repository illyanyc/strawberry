# UI

**Prefix:** `UI-`  ·  **Owners:** `apps/web`, `api-gateway` (BFF endpoints)  ·  **Related:** [security.md](security.md), [risk-management.md](risk-management.md), [ADR-0012](../adr/0012-web-ui-spa-sse-pwa.md)

## Scope

Presentation rules for the web UI on desktop and mobile: page inventory, PAPER/LIVE conventions, dangerous-action UX, real-time behavior. Authorization, step-up, and validation are server-side (`security.md`); the UI only reflects them.

## Concepts and states

- **Page inventory (Phase 0):** login, first-run setup, dashboard, security (passkeys, authenticator app, recovery codes, sessions), broker connections (write-only), platform settings, audit log.
- **Page inventory (Phase 2):** dashboard accounts summary and strategy cards, Portfolio, Strategies list and detail, Orders blotter with trace, Manual order ticket, Charts, Risk & kill switches. Later slices add backtests (3), training/experiments/assistant (4), monitoring and the alerts inbox (5).
- **Page inventory (Phase 4 research slice):** Training (new job form, jobs, runs), job progress, run detail (metrics, diagnostics, importance, model card, registration, tearsheet link), Experiments (lineages), lineage detail (ledger, statistics, cycle, holdout, analyst autonomy, retraining, studies, candidates), study detail, candidate detail (gate report, promotion, holdout evaluation, champion vs challenger). The backtests page (section 14 slice 3) and the assistant pages are separate slices.
- **Research resources:** `/api/v1/research/*` returns protojson of `tb.ml.v1` / `tb.optimizer.v1` messages; progress streams are SSE `progress` events (the upstream sequence is the event ID) ending with `done`.
- **Page inventory (Phase 4, analyst slice):** AI analyst page (`/analyst`): loop status and autonomy selector, research journal, trial ledger, code proposals, and chat with evidence citations (rules in [assistant.md](assistant.md)).
- **Page inventory (Phase 5, full UI):** rebuilt dashboard; Portfolio overview with an end-of-day tab (`/overview`); Backtests & tearsheets (`/backtests`, `/backtests/runs/$runId`, `/backtests/compare`); Charts with split layouts, indicators, and signal overlays; Data explorer (`/data`); Notifications (`/settings/notifications`); TradingView (`/settings/tradingview`). Section 13's monitoring pages (strategy health, drift, divergence, alerts inbox, daily reports) join the shell's `operations` section ([ADR-0050](../adr/0050-full-ui-shell-design-system-and-performance.md)).
- **Shell:** environment banner, header (brand, live/stale indicator, search, shortcuts, theme, kill switch, log out), status strip, sidebar grouped into Overview, Trading, Research, Operations, Settings (collapsible to icons); on phones a tab bar (Home, Portfolio, Strategies, Charts, More) with the kill switch in the header.
- **Trading status:** streamed over SSE (`trading-status`): environment, live flag, session expiry, and execution's `TradingStatus` (global state; per account: session, reconciliation, margin flags, day-trade count and PDT mode; strategy health; active kill switches and halts).
- **Trading resources:** the gateway returns the canonical protojson form of the `tb.*` messages (camelCase, every field emitted; decimals `{value}`, int64 ns strings, full enum names; ADR-0028), typed in the UI by the generated `*Json` types. The UI displays what services compute and never derives P&L, ownership, or risk.

## Edge cases

| Scenario | Expected behavior | Rules |
|---|---|---|
| Owner signed in with TOTP tries to enable live trading | Step-up dialog offers passkey only; TOTP is not accepted | UI-002, SE-014 |
| Session revoked from another device while dashboard is open | SSE sends `session-ended`; UI navigates to login | UI-004, SE-005 |
| Gateway restarts | EventSource reconnects automatically; indicator shows stale until the next event | UI-004 |
| Execution is down while the dashboard is open | Status bar shows "Execution: unknown"; the kill switch button stays enabled and reports the 503 if pressed | UI-013, UI-006 |
| Owner tries to release a kill switch from a phone | Gateway answers `desktop_required`; execution would refuse it too | UI-006, RM-007 |
| Owner signed in with TOTP releases a kill switch | Step-up dialog offers passkey only; cancel leaves the switch latched | UI-006, SE-014 |
| Manual sell larger than the manual quantity in a ticker a strategy also holds | Preview shows the failed ownership check; submit stays disabled | UI-015, VP-003 |
| Chart client falls behind a fast stream | Gateway sends `resync` and closes; the UI reloads history and reconnects | UI-012 |
| Ticker unknown to the instrument master | "Unknown symbol" error; nothing is charted or ordered | UI-011 |
| Owner edits a hyperparameter after estimating | The launch button returns to "Estimate"; the old estimate cannot launch the new config | UI-023, ML-031 |
| Family schema has a keyword the form does not support | A warning lists the property; the server default applies | UI-023 |
| ml or optimizer is down | Research pages show the 503 error per card; nothing is cached as healthy | UI-007, UI-024 |
| The holdout look for this family and quarter is spent | Counter shows 0 remaining; the evaluate button is disabled; the server refuses anyway | UI-026, EX-011 |
| Owner signed in with TOTP promotes to paper | Step-up dialog offers passkey only; cancel leaves the stage unchanged | UI-026, SE-014 |
| A model card contains HTML | Rendered as text; no element is created | UI-023, UI-005 |
| Assistant service is down | Analyst page shows "assistant unavailable"; trading pages are unaffected | UI-007, UI-018 |
| Owner cancels the step-up while raising autonomy | Level stays unchanged; an error is shown | UI-019, UI-002 |
| A page chunk is missing after a deploy | "Reload the app" in the page area; the shell and kill switch keep working | UI-043 |
| marketdata is down | Status strip shows "Feeds: unknown"; charts show their error state | UI-013, UI-049 |
| Phone owner opens the palette | Not available on phones (no keyboard); the "More" sheet lists every page | UI-041, UI-042 |
| iPhone in Safari (not installed) opens Notifications | Explains that push needs Add to Home Screen; no subscribe button | UI-044 |
| A strategy publishes signals on the old `sig.<strategy_id>` subject | Not in chart history (needs the instrument token, ADR-0051) | UI-049 |
| Two runs compared, one lacks a metric | That cell shows "—"; no difference column exists | UI-047 |

## Open questions

- Virtualized blotter for 10k rows: Planned (the blotter pages 2,000 rows).
- Data explorer: coverage and gap reports per backfill, data-quality findings, and the context-event timeline aligned to the chart are Planned (they need marketdata and context-data read APIs).
- Backtests: plotting a run's trades on the chart and a backtest launch form separate from training are Planned (training runs already produce walk-forward backtests).
- Settings: universe and data-source editors are Planned.
- 50k-bar charts: the chart library handles them, but the bar cache serves at most 500 bars per timeframe (UI-010); lake-backed history is Planned.

### Fixed

- Backup drill failed with "lake differs": after a restore, marketdata's catch-up of the last 72 h of scheduled jobs re-exported `ref/*.parquet` with a new `tb.exported_at`, changing bytes for identical data. `lake.WriteRef` now stores a content digest (`tb.content_sha256`) and skips unchanged exports, `refdata.Export` sorts every table, and Parquet key-value metadata is written in sorted key order (ST-001). The drill prints the differing files on failure.
- Flaky tests found by repeated non-race runs: the broker contract suite missed a disconnect when the adapter reconnected before the first poll (it now also accepts a newer `state_since`); backfill data-quality checks reported `non_monotonic` when a ticker change split a chunk into per-symbol requests returned in map order (bars are now sorted by instrument and time before the check, MD-001). The U8 latency test failed under `-race` on a 2-vCPU CI runner (p99 1.18 s): the 500 ms target is now asserted without the race detector (`make perf` runs it) and `-race` runs only fail on a gross regression (> 5 s).
- CI secret scan flagged an Alpaca page cursor in `tests/fixtures/alpaca/bars_1min.json` as a generic API key; the fixture now uses an obviously synthetic cursor and `.gitleaks.toml` allowlists JSON vendor fixtures under `tests/fixtures/` (history keeps the old cursor; it is not a secret).
- Removed two accidentally committed build outputs (`services/marketdata/marketdata`, `tools/tbctl/tbctl`, ~50 MB of ELF binaries) and ignored per-module `go build` outputs in `.gitignore`.
- Browser e2e: the credential-status assertion matched the success message as well as the list item (flaky strict-mode failure in CI); it now targets the list item.
- `scripts/check-arm64.sh` retries registry lookups and reports registry errors separately from missing arm64 variants (Docker Official Images failed the first CI run without an error message).
- `golang.org/x/net` upgraded to v0.60.0 in every Go module (CVE-2026-78669, HTTP/2 SETTINGS flood; found by Trivy).
- `tests/e2e` skips unless `TB_E2E_BASE_URL` is set, so unit-test runs never depend on a running stack.
- Web UI bugs found by the first real-browser run: `formatTime` combined `dateStyle`/`timeStyle` with `timeZoneName` (rejected by browsers, crashing the security page); the dashboard showed the previous session's data after logout/login (query cache now cleared, UI-009); the SSE hook re-subscribed on every render; the PAPER/LIVE banner lagged a settings change by up to 15 s (UI-004).
- api-gateway panicked at startup when serving the UI: `GET /` conflicted with the `/api/` catch-all in Go's ServeMux. The SPA handler now registers on `/` and rejects non-GET/HEAD itself; `TestStaticUIServing` covers SPA fallback, assets, unknown API paths, traversal, and CSP.

## [Unreleased]

### Added

- Strategy publications (UI-052): an authenticated user can publish a strategy definition and the non-performance parameters of a hypothetical backtest (window, bar size, universe description) at `POST /api/v1/publications`. The index (`GET /api/v1/publications`, page `/publications`) orders by publication time or title only. Profit, return, Sharpe, drawdown, win rate, rank, signals, and orders are rejected and are not stored. Each entry is labeled user content and is not advice from Alpha Inertia LLC. There is no deploy, copy, follow, or order route. Reads use `research.read`; create and withdraw use `research.launch`. Stored in `config.publications` (migration `config/000002`). **Refused:** a cross-user board of money made, and any public ranking or display of backtest returns. Those would be an analysis of securities and a performance advertisement; the adviser-status memorandum does not support them.

- Gate 5 monitoring harness `make monitoring-gate` (MN-032, MN-035, MN-037, MN-038, RM-018, SE-040; run in CI): the Python monitor core contains injected feature drift (warning alert, then halted), injected live-vs-backtest divergence on the recorded paper sessions (paper → halted, then live → paper through a latched kill switch), and a drawdown beyond 1.5× the backtest p95 on a live strategy, all through execution's `DemoteStrategy` behind the production service-token interceptor. Working entries are canceled, protective stops and positions stay, manual is untouched, and every demotion is audited with the monitor's reason; writes `monitoring-gate-evidence.json`. A static test now checks the monitor dead-man path to Pushover emergency priority (MN-007).

- Monitoring page in the web UI (UI-028..UI-031, MN-030..MN-042): `/monitoring` lists each strategy's health score and components; a strategy's tabs show performance against the backtest band, feature drift, daily divergence with recording completeness, execution quality, graduation evidence, and containment (policy editor and automatic actions). The page also has the alert inbox (acknowledge; silence with a reason and a passkey) and daily reports. Values are the monitor's; the page computes none.
